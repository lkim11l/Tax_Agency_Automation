# Codex Task Template

Use this template for every new Codex session.

```text
Read AGENTS.md and all mandatory project documents before making changes.

Work only on the first incomplete task in docs/CURRENT_SPRINT.md.
Do not jump to later roadmap phases.
Do not add visual polish or out-of-scope features.
Do not weaken the human approval requirement.
Do not fabricate missing business or legal data.

Before coding:
1. inspect the repository and git status;
2. identify the exact roadmap item;
3. explain the smallest complete implementation you will make.

After coding:
1. run lint, typecheck, tests, and build;
2. update docs/CURRENT_SPRINT.md;
3. update docs/DECISIONS.md only if an architectural decision was made;
4. report completed work, files changed, validation results, limitations, and the next allowed task.

Begin with the current sprint.
```
