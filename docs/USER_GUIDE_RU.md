# Руководство оператора

## Начало работы

Войдите через `/login`. Самостоятельная регистрация отключена. Основная работа
ведётся в разделах «Заявки», «Контрагенты», «Шаблоны», «Реестр», «Отчёты» и
«Состояние системы». Язык RU/EN сохраняется в защищённой cookie; по умолчанию
используется русский.

## Обработка заявки

1. Откройте новую заявку и проверьте письмо и вложения.
2. Если файл помечен `OCR_REQUIRED`, обработайте его вручную: OCR в пилот не входит.
3. Сверьте извлечённые поля с источниками. Конфликт или низкая уверенность
   требуют ручной проверки.
4. Проверьте заполненность. Пустые юридически значимые поля нельзя угадывать.
5. Подготовьте уточнение, проверьте получателя и текст, затем отдельно одобрите
   отправку.
6. После ответа клиента снова проверьте источники и заполненность.
7. Создайте договор только из одобренного шаблона, скачайте и прочитайте точную
   версию. Одобрение привязано к контрольной сумме.
8. Отправляйте договор только после явного одобрения. При неопределённом
   результате SMTP не повторяйте отправку до сверки почтового ящика.

Администратор контролирует компоненты и фоновые запуски на `/settings`. Красный
или устаревший статус необходимо разобрать по `INCIDENT_RESPONSE.md`.
